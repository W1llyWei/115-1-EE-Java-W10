# 115-1-EE-Java-W10

第 10 週 Java 課程例題：**方法（method）的定義與呼叫**。

程式碼放在 `src/ch10/`，套件名稱為 `ch10`。

## 例題一覽

| 檔案 | 主題 | 重點 |
|------|------|------|
| `Ex1.java` | 等差數列和（`void` 方法） | 方法沒有回傳值，直接在方法內 `println` 印出結果 |
| `Ex2.java` | 等差數列和（`int` 回傳值） | 同一題改用 `return total;`，由 `main` 決定怎麼印 |
| `Ex3.java` | 攝氏轉華氏 | 傳入 `double`、回傳 `double`；公式 `F = C × 9 / 5 + 32` |
| `Ex4.java` | 找 5 個整數的最大值 | **陣列當參數**：方法內排序會改到 `main` 裡的原陣列（傳的是參考） |
| `Ex5.java` | 3×3 矩陣轉置 | **二維陣列當參數**；只交換對角線下方 `j < i` 的元素，避免換兩次又換回來 |

### Ex1 vs Ex2：`void` 與回傳值
- `static void sum(...)`：方法做完事就結束，呼叫端拿不到結果。
- `static int sum(...)`：用 `return` 把結果交回去，呼叫端可以拿來印、存、再計算 → 比較有彈性。

### Ex3：基本型別是「傳值」
`transform` 裡面改了 `c`，但 `main` 裡的 `c` 不會變，因為傳進去的是一份複本。

### Ex4、Ex5：陣列是「傳參考」
傳進方法的是陣列的位址，所以方法內 `Arrays.sort`、交換元素，都會直接改到原本的陣列，
方法不必 `return` 也看得到結果。（對照 Ex3 的基本型別行為。）
